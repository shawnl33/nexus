# 대시보드 행·열 추가 설계

날짜: 2026-10-03
상태: 사용자 승인됨 (헤더의 `+ 차트`를 `행추가`·`열추가`로 바꾸고, 새 칸은 바로 위 또는 왼쪽 칸을 복사한다)

## 목적

헤더의 `+ 차트` 한 버튼 대신 `행추가`와 `열추가`로 화면 전체의 차트 격자를 늘린다. 행을 더하면 맨 아래에 한 줄이 생기고, 열을 더하면 맨 오른쪽에 한 열이 생긴다. 이미 나뉜 행과 열은 유지된다. 새 칸은 맞닿은 칸의 종목·지표·캔들 모양·Data2를 복사한다.

## 현재

`#panes`는 세로 한 줄이다. 칸마다 `heightFrac`가 있고, 합은 1이다. `+ 차트`(`#pane-add`)는 맨 아래에 칸을 하나 더하고, 보고 있던 칸의 종목·지표·캔들 모양·Data2를 복사한다. 경계 드래그는 위아래뿐이고 최소 비율은 0.1이다. 화면틀 스키마 2의 `panels`는 위→아래 목록이고 칸마다 `height`가 있다. 열 정보는 없다.

시간축 동기화는 칸마다 오른쪽 끝 시각과 px 봉 간격을 맞춘다. 세로로 쌓인 칸은 차트 오른쪽 끝이 같은 화면 x라서 같은 시각이 같은 x에 놓인다. 이 계산은 `pane-sync.js`에 있고, 각 칸의 차트 폭(`getWidth`)을 쓴다.

## 배치

화면은 직사각형 격자다. 모든 행의 열 수는 같다.

- 행 높이는 행마다 하나다. 같은 행의 칸은 높이를 나눠 갖지 않는다. 행 높이의 합은 1이다.
- 열 너비는 열마다 하나이고 모든 행이 같이 쓴다. 열 너비의 합은 1이다.
- DOM은 `#panes` 안의 행이고, 행 안에 칸이 왼쪽부터 놓인다. 칸 본문(지표 패널 | 차트)은 지금 구조를 유지한다. 칸은 자기 행의 높이를 채우고, 자기 열의 너비를 쓴다.
- 평탄한 `panes` 목록은 유지한다. 순서는 왼쪽에서 오른쪽, 위에서 아래다. 종목 해지, 시딩, 시간축 동기화, 화면틀 저장은 이 목록을 그대로 순회한다.

예시. 2행 2열에서 열추가를 누르면 2행 3열이 된다. 새 오른쪽 칸은 각 행의 바로 왼쪽 칸을 복사한다.

```
[ A ][ B ]          [ A ][ B ][ B ]
[ C ][ D ]    →     [ C ][ D ][ D ]
```

같은 화면에서 행추가를 누르면 3행 2열이 된다. 새 아래 칸은 각 열의 바로 위 칸을 복사한다.

```
[ A ][ B ]          [ A ][ B ]
[ C ][ D ]    →     [ C ][ D ]
                    [ C ][ D ]
```

## 헤더

`#pane-add`(`+ 차트`)를 제거한다. 그 자리에 다음 두 버튼을 둔다. 왼쪽 지표 패널에는 넣지 않는다.

| id | 문구 | title |
| --- | --- | --- |
| `row-add` | 행추가 | 맨 아래에 행을 추가한다 |
| `col-add` | 열추가 | 맨 오른쪽에 열을 추가한다 |

시작 화면은 지금과 같이 1행 1열이다.

## 추가

행추가와 열추가가 만드는 칸은 같은 복사 규칙을 쓴다.

복사하는 값:

- 종목 코드와 종목명
- 켜진 지표의 id와 레이어 설정
- 캔들 모양(`barStyle`)
- Data2 참조 코드

복사하지 않는 값:

- 지표 패널 접힘. 새 칸은 패널이 열린 채로 시작한다.
- 지표 트리의 접힘, 검색 입력, 보이는 시간 범위

원본 칸에 종목이 없으면 새 칸은 빈 차트다. 지표와 Data2도 복사하지 않고, 캔들 모양은 기본값(캔들바)이다.

종목이 있으면 지금 `addPane`과 같은 순서로 기존 함수만 쓴다. `selectPaneSymbol`, `activateIndicator`, `setPaneData2`, `setBarStyle`. 종목 선택이 실패하면 그 칸은 지표를 올리지 않는다. 알림은 지금 `selectPaneSymbol`이 띄우는 것을 그대로 쓴다. 같은 추가 안의 다른 새 칸은 계속 진행한다.

새 칸은 한 번에 하나, 순서대로 만든다. 행추가는 왼쪽 열부터, 열추가는 위 행부터다. 추가가 진행되는 동안 로딩 베일은 한 번만 덮인다.

비율:

- 행추가: 먼저 행 높이 합을 1로 맞춘다. 새 행의 높이는 `1 / (기존 행 수 + 1)`이고, 기존 행 높이는 각각 `(기존 행 수) / (기존 행 수 + 1)`를 곱한다.
- 열추가: 열 너비도 같은 방식이다. 새 열의 너비는 `1 / (기존 열 수 + 1)`이고, 기존 열 너비는 각각 `(기존 열 수) / (기존 열 수 + 1)`를 곱한다.
- 추가 결과 어떤 행·열의 비율이 0.1보다 작아져도 추가는 된다.

칸이 하나도 없으면 행추가와 열추가 모두 빈 칸 하나를 만든다. 복사는 없다.

복사 원본은 보고 있던 칸이 아니다. 행추가의 각 새 칸은 그 열의 맨 아래 칸을 복사하고, 열추가의 각 새 칸은 그 행의 맨 오른쪽 칸을 복사한다. 추가가 끝나면 마지막으로 만든 칸을 현재 칸으로 둔다.

## 크기 조절

- 행 경계는 지금과 같이 위아래 드래그다. 손잡이는 행과 행 사이, 화면 폭 전체다. 맞닿은 두 행만 바꾸고, 둘 다 0.1 아래로 줄지 않는다.
- 열 경계는 좌우 드래그다. 손잡이는 열과 열 사이, `#panes` 높이 전체로 하나다. 칸마다 따로 두지 않는다. 맞닿은 두 열만 바꾸고, 둘 다 0.1 아래로 줄지 않는다. 모든 행의 그 열이 함께 움직인다.
- 드래그 뒤 차트 크기는 각 칸의 차트 영역 크기에 맞춘다.

## 삭제

칸의 `×`는 격자 모양에 따라 행 또는 열을 지운다. 칸 하나만 빼서 직사각형을 깨지 않는다.

- 행이 둘 이상이면 그 `×`가 있는 행 전체를 지운다. 남은 행 높이는 지우기 전 비율대로 합이 1이 되게 나눈다.
- 행이 하나이고 열이 둘 이상이면 그 `×`가 있는 열 전체를 지운다. 남은 열 너비도 같은 방식으로 나눈다.
- 행도 열도 하나이면 그 칸을 지운다. 칸이 0이 될 수 있다. 이것은 지금 마지막 칸 삭제와 같다.

2행 이상에서는 `×`로 열을 지우지 못한다. 열을 지우려면 행이 하나가 된 다음 `×`를 누른다.

`×`의 title은 칸 수가 바뀔 때마다 맞춘다.

| 조건 | title |
| --- | --- |
| 행이 둘 이상 | 이 행 삭제 |
| 행이 하나이고 열이 둘 이상 | 이 열 삭제 |
| 1행 1열 | 이 차트 삭제 |

지운 칸의 종목은 다른 칸이 보지 않으면 지금처럼 관측을 해지한다.

## 시간축

`pane-sync.js`는 고치지 않는다. 좌우로 놓인 칸은 화면의 같은 x를 공유하지 않는다. 각 차트 안에서 오른쪽 끝 시각과 px 봉 간격이 같다. 넓은 열은 왼쪽에 더 많은 봉이 보인다. 지표 패널을 접으면 그 칸의 차트만 넓어지고, 열의 오른쪽 끝은 그대로다.

## 화면틀

스키마 버전은 2를 유지한다. 서버는 JSON을 그대로 저장하므로 서버 코드는 고치지 않는다. `serialize`가 항상 다음을 넣는다.

- `cols`: 1 이상의 정수. 열 수.
- `colWeights`: 길이 `cols`인 양수 배열. 합은 1.
- `panels`: 길이 `행 수 × cols`. 왼쪽→오른쪽, 위→아래. 한 행의 모든 칸은 같은 `height`(그 행 높이)를 저장한다. 칸의 나머지 필드(종목, 패널 접힘, Data2, 캔들 모양, 지표)는 지금과 같다.
- `current_symbol`: 지금처럼 첫 칸의 종목.

`cols` 인자를 생략한 `serialize`는 `cols: 1`, `colWeights: [1]`을 쓴다. 기존 호출이 그대로 동작한다.

`parse` 결과에는 `cols`와 `colWeights`가 더해진다. `panels`는 평탄한 행 우선 목록이다.

읽는 규칙:

- `schema_version`이 2가 아니면 `null`이다. 지금과 같다.
- `cols`가 없거나 1 이상의 정수가 아니면 1로 본다.
- `panels.length`가 `cols`로 나누어 떨어지지 않으면 `cols`는 1이고, 저장돼 있던 `colWeights`는 쓰지 않는다. 칸은 모두 한 열로 쌓인다.
- `colWeights`가 없거나 길이가 `cols`와 다르거나, 숫자가 아니거나, 0 이하이거나, 합이 0이면 열 너비는 `1/cols`로 같다. 쓸 수 있는 값이면 합이 1이 되도록 나눈다.
- 행 높이는 그 행 첫 칸의 `height`다. 같은 행의 나머지 칸의 `height`는 무시한다. 높이 클램프(0.1~1, 누락 시 1)는 지금과 같다.
- 불러온 뒤 행 높이 합과 열 너비 합은 각각 1로 맞춘다.

이 필드가 없는 기존 화면틀은 열이 하나인 세로 목록으로 열린다.

## 바꿀 파일

- `web/public/index.html`: 버튼과 행·열 크기 조절 스타일
- `web/public/app.js`: 격자 생성, 행추가, 열추가, 행·열 삭제, 크기 조절, 화면틀 적용
- `web/public/workspace.js`: `cols`, `colWeights` 직렬화·파싱
- `web/test/workspace.test.js`: 아래 검증의 단위 테스트

`pane-sync.js`, 엔진, `web/server.js`는 고치지 않는다.

## 검증

`workspace.test.js`:

- `serialize`가 `cols`와 `colWeights`를 쓴다. 격자 인자가 없으면 열 하나다.
- 2행 2열 왕복에서 열 수, 열 너비, 행 높이, 종목, 지표가 유지된다. 한 행의 두 칸은 같은 높이를 저장한다.
- `cols`가 없는 스키마 2는 열 하나로 읽힌다.
- `cols`가 칸 수를 나누지 못하면 열 하나로 읽고 칸은 버리지 않는다.
- 잘못된 `colWeights`는 균등 너비가 된다.

브라우저에서 `http://127.0.0.1:18080`:

- 행추가가 맨 아래에 행을 만들고, 각 칸이 바로 위를 복사한다.
- 열추가가 맨 오른쪽에 열을 만들고, 각 칸이 바로 왼쪽을 복사한다.
- 행 경계와 열 경계를 드래그하면 맞닿은 둘만 변하고 10% 미만으로 줄지 않는다. 열 경계는 모든 행이 함께 움직인다.
- 2행 이상에서 `×`는 그 행을 지운다. 1행 2열 이상에서 `×`는 그 열을 지운다. 마지막 칸도 지워진다.
- `cols`가 없는 기존 화면틀은 한 열로 열린다. 행·열을 만든 화면틀을 저장한 뒤 불러오면 같은 격자와 칸 내용이 돌아온다.
- 좌우 칸의 시간축은 오른쪽 끝 시각과 봉 간격이 같다.

## 범위 밖

- 칸 하나만 지우기, 행마다 다른 열 수
- 보고 있던 칸만 나누기
- 시간축 동기화 알고리즘 변경
- 지표 전용 하위 차트 행을 가격 칸 아래에 다시 쌓기
- 왼쪽 지표 패널에 차트 추가 버튼을 두기
- 좁은 열에서 200px 지표 패널의 폭을 바꾸기
