## 2. 파일별 계약 요약

### 2.1 woodstock_mirae_curve_1m_v16.txt (메인 지표, 998줄)

- 함수가 아니라 차트 지표 본문. Input 28개, 출력은 Plot 1·7·20–22·30–55 + TL(목표선/상하단선).
- 회귀 입력 가격: `(H+L)/2`. 회귀 상태: 구형 7인자 V3 가정(미제공).
- 주요 출력: 통합 점수(Plot1, 이론상 −7..+7), 회귀선(Plot7), 과거예측 검증(Plot20–22), 매매상태(Plot30/31), 방향 전환 고정 기억선(Plot32–41), 지속선(Plot42–50), 마켓 밴드(Plot51–55), TL 진행 예측선.
- 고정 기억선: `곡선회귀유효==1 && 방향!=0 && 예측가격!=0 && 방향 전환`인 봉에만 저장, 틱 단위 양자화(`round(x/PriceScale,0)*PriceScale`), 세션 변경 시 리셋(30분 이하 분봉).
- 세션 처리: `DayIndex==0`을 당일 첫 봉(세션 경계)으로 사용, `BDate<>BDate[1]`을 날짜 경계로 사용. 두 의미가 다름을 각각 보존한다 (계획서 §8).
- 죽은 코드 다수: 115–186줄 전체(곡선가격판정·회귀ADX·DI 체인), MTF방향선ID(TL_New 없음), 미사용 출력 다수 → 포팅 시 결과 무영향 확인 후 제외.

### 2.2 WSF_Mtf_LinRegV3.txt (제공 정의, 192줄, 19인자)

- IN 4개(회귀가격입력, 예측봉수1–3) + OUT 15개. 반환값 상수 1.
- 상태: `회귀가격[100]` 시프트 배열([0]=최신), `유효개수`, `최근날짜/시간`(-1 초기).
- 새 봉 판정: `sDate/sTime` 변화. 새 봉 → 1칸 시프트 + 유효개수 증가(상한 n). 같은 봉 → 매 평가 `회귀가격[0]` 덮어쓰기.
- 장 시작 리셋: 30분 이하 분봉에서 `DayIndex==0`이면 배열 전체 0 클리어 + 유효개수=0.
- 회귀기간 n 자동 선택: 틱/초/1분 이하 30, ≤5분 18, ≤15분 10, ≤30분 6, 기타 분봉 12, 일봉 20, 주봉 13, 월봉 12.
- 유효 조건: 계산개수 ≥ 최소회귀봉수(5). 무효 시 회귀선=입력가격, 나머지 0, 회귀유효=0.
- R²(회귀신뢰도): 피어슨 상관 제곱 형태, [0,1] 클램프. **예측 성공 확률이 아니다** (계획서 §10.3).
- 잔차: sqrt(SSE/(N−2)), SSE=SST*(1−R²).
- 낶부에서 V4를 16인자로 호출(172–189) → 신형 V3는 예측 출력까지 자체 생산.

### 2.3 WSF_Mtf_LinRegPredictV4.txt (94줄, 16인자)

- IN 7(현재회귀선, 회귀기울기, 유효, 신뢰도, 예측봉수1–3) + OUT 9(예측가격1–3, 예측방향1–3, 보정기울기, 기울기가속도, 예측변동성).
- 신뢰계수: `(R²−0.20)/0.50`을 [0,1] 클램프 → R²≤0.20이면 예측 평탄화, ≥0.70이면 전량 반영.
- 보정기울기: 기울기×신뢰계수, ±0.50·ATR(14) 클램프.
- 가속도: `(기울기−기울기[3])/3`×신뢰계수, ±0.08·ATR 클램프. **보정기울기와 같은 부호(추세 가속)면 0으로 억제** — 둔화/반전 성분만 사용. 30분 이하 분봉에서 3봉 창이 일자 경계를 걸치면 0.
- 이동값k: `보정기울기·n + 0.5·가속도·n²`, 상한 `1.50·ATR·√max(1,n)`.
- 예측방향: 이동값 부호 −1/0/+1 (열거값).
- 무효 시: 예측가격=현재회귀선(평탄), 방향=0.
- 불명: 내장 `ATR(14)`의 산식(Wilder 여부)·시딩, 차트 초기 1–3봉의 `[3]` 평가값.
- 워밍업: 실질 ≥15봉 (ATR 14 + [3]).

### 2.4 WSF_Htf_CurvePredict.txt (74줄, 6인자)

- IN 1(곡선예측틱수) + OUT 5(곡선하/곡선상/곡선예측가격/변화/방향).
- 표본: `(L+H)/2` 최근 19개, 수동 시프트 배열(MinClose[100], 0 초기 채움). x좌표는 누적 카운터 X 기반.
- 곡선예측가격 = `MinLRS*(X+곡선예측틱수)+MinB` — **후처리 없는 원시 외삽** (R²/ATR 감쇠 없음).
- **방향 = 곡선예측가격 − 곡선하 (가격 단위 수치). -1/0/+1 열거가 아니다** (계획서 §10.3, 원본 71줄 직접 확인).
- 곡선하 = `MinLRL[k+1]` — k가 매 평가 0으로 리셋되어 실효 `MinLRL[1]` (직전 평가 회귀값).
- `DayIndex()%1==0` (15줄): 정수 %1은 **항상 참**. k 카운터·변곡 감지(64–67)는 깨져 있고 출력 무영향 → 원본 호환 구현에서도 수치 동일. 서브샘플링 게이트 의도였을 것으로 추정되나 불명.
- V3/V4와 **별도 회귀 상태**. 공통 회귀 유틸 재사용은 가능하나 이력을 합치지 않는다 (계획서 §10.3).
- 워밍업: 현재값 출력 19봉, [1] 의존 출력 포함 20봉. 그 전에는 0 채움 쓰레기값.

### 2.5 WSF_OrderBookDirectionV2.txt (181줄, 7인자)

- IN 3(관심기준, 강세기준, 부호반전) + OUT 4(호가방향점수, 호가기울기3, 호가방향상태, 호가유효).
- `Bids`/`Asks` 내장 식별자 직접 참조. **몇 단계 호가 합계인지 원본만으로는 불명** → LS 필드 매핑 시 확인 필요 (계획서 §10.3).
- 잔량차이: 선물(CodeCategory==4)은 매수−매도, 주식은 매도−매수. 부호반전입력==1이면 반전.
- 점수: 잔량차이점수(러닝평균 대비 %, ±100 클램프)·잔량비율점수(전체 대비 %, 클램프는 도달 불가) → 핵심점수=(60:40 가중). 방향점수=(핵심60 + 평균3 25 + 평균5 15)/100.
- 기울기3: 방향점수 − 방향점수[3], ±100 클램프. 상태: ±2(강세)/±1(관심)/0.
- 일자 변경(BDate) 시 상태 리셋. 유효 조건: 전체잔량>0. **호가 없는 종목은 유효=0으로만 처리 — 0이나 다른 데이터로 채우지 않는다** (계획서 §18).
- 워밍업: 일별 유효 호가 평가 5회. 무효 봉에서 시계열이 이월되는 의미는 플랫폼 규약(불명) → C 포팅 시 갱신 조건 명세 필요.

### 2.6 WSF_MiraeCurve1mFullOutputV1.txt (705줄, 69 OUT)

- 메인 지표의 표시값을 Plot/TL 없이 OUT_* 69개로 리턴하는 계산 분리 함수 (IN 21 + OUT 69, 반환 상수 1).
- 메인과 같은 호출 체계(V3 7인자 ×2, V4 16인자 등) + 30/60분 목표를 V4 수식 복제로 인라인 확장.
- DailyTrendLinkV1→GapRegimeV1→DailyAlignV2 체인(미제공 3종)에 운영최종* 출력이 전적으로 의존 → 해당 출력군은 원본 확보 전까지 포팅 불가.
- 헤더가 "원본 행 번호"를 인용하며 제외 항목(TL, 색상, 죽은 코드)을 명시 — 메인보다 약간 다른 버전 기준으로 작성된 흔적(Plot60~97 언급은 메인에 없음). **메인과 완전히 같은 버전으로 간주하지 않는다** (계획서 §10.1).

| P01 | V3 호출 7인자 vs 제공 정의 19인자 | **확정**. 메인·FullOutput 모두 7인자 호출(원본 66–69, 941–942 직접 확인). 메인은 "구형 V3(7인자, 미제공) + 외부 V4" 체계. 제공 신형 V3는 V4 내장. 포팅은 메인 기준 체계(7인자 V3 + 외부 V4)로 하되, 구형 V3 정의는 미제공이므로 신형 V3의 회귀 6종 출력 부분과 동등한지는 비교 불가(불명) |

## 5. 포팅 단위 제안 (독립 계산부 우선, 단계 3)

1. **회귀 유틸리티**: OLS 적합(기울기·절편·R²·잔차) — V3(19표본 아닌 n 가변)와 Htf(19표본)가 공유 가능. x좌표 0..N−1 상대좌표 사용 시 Htf의 절대 X와 수학적 동등(단, 원본 호환 검증 필요).
2. **WSF_Htf_CurvePredict** — 독립·완전 제공. 워밍업 19/20봉, 방향=수치.
3. **WSF_Mtf_LinRegPredictV4** — 완전 제공. 단 내장 `ATR(14)` 산식이 불명 → ATR을 Wilder/단순 중 선택해 버전 기록하고, 원본 비교 자료 확보 시 교정.
4. **WSF_OrderBookDirectionV2** — 완전 제공. Bids/Asks 합계 범위는 LS 매핑 시 결정.
5. **WSF_Mtf_LinRegV3 (제공 신형)** — 완전 제공. 회귀 6종 + 낶부 V4. 메인의 7인자 구형과의 관계는 불명 기록.
6. **메인 지표의 독립 계산부**: 과거예측 검증(가변 룩백 [예측봉수k]), 고정 기억선/지속선 상태 기계, 마켓(분봉 VWAP·가중표준편차), 통합 점수(방향 0 → −2 분기 포함).
   → **구현 완료 (2026-09-28)**: `past_prediction`, `memory_lines`(회귀기억·지속선), `market_profile`(분봉), `score_1m`. 통합 점수에서 마켓 중심은 원본 951줄의 `Average((H+L)/2, 마켓계산기간)` 단순 평균을 사용함(분봉 마켓 프로파일의 VWAP과는 별도 계산임에 주의).
7. **MISSING_DEPENDENCY 표시부**: 운영최종·호가 V1 의존 출력.

## 6. 공통 포팅 주의점

- 반환값은 전 함수가 상수 1 — C 구현에서는 무시하고 OUT 구조첧만 정의.
- YesLanguage `var`는 미대입 시 이월 → C에서는 명시 상태 구조체 + 갱신 조건으로 표현. 매 봉 기본값 리셋(V3 109–114)과 조걶 이월(회귀기억*, 호가 무효 봉)을 구분.
- `[예측봉수k]` 같은 **가변 룩백** 필요 (고정 인덱스 링으로 부족).
- 무효 표현은 NaN이 아니라 플래그+기본값 → `tr_validity_t`와 매핑.
- 호가·회귀 상태는 일자/세션 경계 리셋 — bar_builder의 세션 이벤트와 연결.
- R²를 확률로 표시하지 않음, 방향 수치를 열거로 바꾸지 않음 (계획서 §10.3).
