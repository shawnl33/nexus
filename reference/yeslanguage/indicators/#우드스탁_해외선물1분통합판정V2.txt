// #우드스탁_해외선물1분통합판정V2  (하단 오실레이터, 1분봉 전용)
// V2: V1 + 색상 통일 (상승=빨강 계열, 하락=파랑 계열, 방향 무관=회색). 계산부 변경 없음.
//     Plot1: 미래방향·DI방향 중 하나라도 통합상태 방향과 다르거나, 매물대5상태가 반대 부호면 약한 회색 (매물대5상태 0은 불일치로 보지 않음)
// 미래곡선 방향 -> 세션 5선 매물대 -> 세션 ADX/DI  (해외선물: 호가 제외)
// 세션 경계 07:00 / 15:30 (WSF_FXSessionKeyV1). 국내 #우드스탁_미래곡선_1분당일통합판정V1의 해외판.
// 사용 함수: WSF_FXSessionKeyV1, WSF_FXCurveV1, WSF_FXADXV1,
//            WSF_FXSessionProfileV1_CO, WSF_FXDecisionV2_CO
Input : 예측변수(10),
        가치영역배수(1.5),
        최소봉수(5),
        ADX기간(14),
        ADX추세기준(20),
        ADX강세기준(35),
        세부값표시(1),
        매물대기준모드(1);
Var : FX세션키(0), FX초기화(0), FX세션봉수(0),
      곡선하(0), 곡선상(0), 곡선예측가격(0), 곡선예측변화(0), 곡선예측방향(0),
      미래방향(0),
      매물대중심(0), 매물대상단1(0), 매물대하단1(0), 매물대상단2(0), 매물대하단2(0),
      매물대5상태(0), 매물대유효(0),
      세션ADX(0), 상승DI(0), 하락DI(0), ADX유효(0),
      통합상태(0), 매물대상태(0), ADX상태(0), DI방향(0),
      통합색상(0), 매물색상(0), 미래색상(0), DI색상(0), 통합방향(0);

FX세션키 = WSF_FXSessionKeyV1(sDate,sTime);
FX초기화 = 0;
If CurrentBar == 1 Then FX초기화 = 1;
Else If FX세션키 != FX세션키[1] Then FX초기화 = 1;
If FX초기화 == 1 Then FX세션봉수 = 1;
Else FX세션봉수 = FX세션봉수[1]+1;

If DataCompress == 2 && BarInterval == 1 Then
{
    WSF_FXCurveV1(FX초기화,FX세션봉수,예측변수,
                  곡선하,곡선상,곡선예측가격,곡선예측변화,곡선예측방향);
    미래방향 = IFF(곡선예측방향 > 0, 1, IFF(곡선예측방향 < 0, -1, 0));
    If FX초기화 == 1 Then 미래방향 = 0;

    WSF_FXSessionProfileV1_CO(FX초기화,가치영역배수,최소봉수,
        매물대중심,매물대상단1,매물대하단1,매물대상단2,매물대하단2,
        매물대5상태,매물대유효);

    WSF_FXADXV1(FX초기화,FX세션봉수,ADX기간,세션ADX,상승DI,하락DI,ADX유효);

    WSF_FXDecisionV2_CO(미래방향,매물대5상태,매물대유효,매물대중심,C,매물대기준모드,
        세션ADX,상승DI,하락DI,ADX유효,ADX추세기준,ADX강세기준,
        통합상태,매물대상태,ADX상태,DI방향);

    통합색상 = IFF(통합상태 == 100, RGB(255,0,0),
               IFF(통합상태 == 50, RGB(255,140,140),
               IFF(통합상태 == -100, RGB(0,0,255),
               IFF(통합상태 == -50, RGB(140,165,255), RGB(150,150,150)))));
    통합방향 = IFF(통합상태 > 0, 1, IFF(통합상태 < 0, -1, 0));
    If 통합방향 != 0 Then
    {
        If 미래방향 != 통합방향 || DI방향 != 통합방향 || 매물대5상태*통합방향 < 0 Then
            통합색상 = RGB(210,210,210);
    };
    매물색상 = IFF(매물대5상태 > 0, RGB(255,90,90),
               IFF(매물대5상태 < 0, RGB(90,130,255), RGB(150,150,150)));
    미래색상 = IFF(미래방향 > 0, RGB(255,90,90),
               IFF(미래방향 < 0, RGB(90,130,255), RGB(150,150,150)));
    DI색상 = IFF(DI방향 > 0, RGB(255,90,90),
             IFF(DI방향 < 0, RGB(90,130,255), RGB(150,150,150)));

    Plot1(통합상태,"당일통합상태",통합색상,Def,3);
    If 세부값표시 == 1 Then
    {
        Plot2(미래방향*80,"미래방향",미래색상,Def,0);
        Plot3(매물대5상태*40,"5선매물대",매물색상,Def,0);
        Plot4(DI방향*20,"DI방향",DI색상,Def,0);
        Plot5(ADX상태*10,"ADX상태",RGB(120,120,120),Def,0);
    }
    Else
    {
        NoPlot(2); NoPlot(3); NoPlot(4); NoPlot(5);
    };
}
Else
{
    NoPlot(1); NoPlot(2); NoPlot(3); NoPlot(4); NoPlot(5);
};
