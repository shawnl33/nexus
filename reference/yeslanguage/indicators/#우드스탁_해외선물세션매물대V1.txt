// #우드스탁_해외선물세션매물대V1  (가격 차트 겹치기, 1분봉 전용)
// WSF_FXSessionProfileV1_CO의 세션 5선을 표시. 세션 경계 07:00 / 15:30.
Input : 가치영역배수(1.5),
        최소봉수(5);
Var : FX세션키(0), FX초기화(0),
      매물대중심(0), 매물대상단1(0), 매물대하단1(0), 매물대상단2(0), 매물대하단2(0),
      매물대5상태(0), 매물대유효(0);

FX세션키 = WSF_FXSessionKeyV1(sDate,sTime);
FX초기화 = 0;
If CurrentBar == 1 Then FX초기화 = 1;
Else If FX세션키 != FX세션키[1] Then FX초기화 = 1;

WSF_FXSessionProfileV1_CO(FX초기화,가치영역배수,최소봉수,
    매물대중심,매물대상단1,매물대하단1,매물대상단2,매물대하단2,
    매물대5상태,매물대유효);

If 매물대유효 == 1 Then
{
    Plot1(매물대상단2,"세션매물상단2",RGB(255,120,120),Def,0);
    Plot2(매물대상단1,"세션매물상단1",RGB(255,170,170),Def,0);
    Plot3(매물대중심,"세션매물중심",RGB(100,100,100),Def,2);
    Plot4(매물대하단1,"세션매물하단1",RGB(170,190,255),Def,0);
    Plot5(매물대하단2,"세션매물하단2",RGB(110,140,255),Def,0);
}
Else
{
    NoPlot(1); NoPlot(2); NoPlot(3); NoPlot(4); NoPlot(5);
};
