// #우드스탁_해외선물매물대압축지속V3  (하단 단독 지표, 1분봉 전용)
// V2 + 방향 확정 신호. 해제 방향이 미확정(회색)이면 압축 당시 박스(1차 상하단)를 기억하고,
//      방향확정봉수 이내에 종가가 처음 박스 밖으로 나가는 봉에 빨강(위)/파랑(아래) 확정 신호.
//      기한 안에 못 나가면 신호 없이 종료. 방향확정봉수=0이면 V2와 같음.
// V1 + 압축 해제 신호. 단계1봉수 이상 이어진 압축이 풀리는 봉에서, 종가가 압축 당시(직전 봉)
//      최근N봉 매물대 1차 상단 위면 +1, 1차 하단 아래면 -1, 사이면 0(방향 미확정)
// 확정봉판정=1이면 해제를 직전 완료봉 기준으로 판정(1봉 늦지만 봉 진행 중 깜빡임 없음)
// 최근 N봉 매물대 폭(1차 상단-하단)이 최근 120봉 최대 폭 대비 좁은 상태가 몇 봉째 이어지는지 표시.
// 세션 경계 07:00 / 15:30에서 초기화. 사용 함수: WSF_FXSessionKeyV1, WSF_FXSessionProfileV2_CO
// Plot1 압축지속봉수: 막대 그래프로 설정 권장. 색 = 회색(단계1 미만) / 연주황 / 주황 / 진주황
// Plot2 폭비율(0~100): 비율표시=1일 때 가는 회색 선
// Plot4 방향확정: Plot3과 다른 모양(예: 다이아몬드/삼각형)으로 설정 권장. 높이=원래 압축 길이
// Plot3 압축해제: 점 그래프로 설정 권장. 높이=해제 직전 압축지속봉수, 빨강=상향/파랑=하향/회색=미확정
//       크기 3/4/5 = 압축 길이 단계1/단계2/단계3 이상
Input : 가치영역배수(1.5),
        최소봉수(5),
        폭계산봉수(30),
        비율기준봉수(120),
        좁음기준(40),
        단계1봉수(15),
        단계2봉수(30),
        단계3봉수(60),
        비율표시(1),
        확정봉판정(0),
        방향확정봉수(5);
Var : FX세션키(0), FX초기화(0), 세션봉수(0),
      매물대중심(0), 매물대상단1(0), 매물대하단1(0), 매물대상단2(0), 매물대하단2(0),
      매물대5상태(0), 매물대유효(0),
      폭(0), 최대폭(0), 폭비율(0), 기준창(0), j(0),
      좁음(0), 압축지속봉수(0), 지속색상(0),
      압축해제(0), 해제방향(0), 해제길이(0), 해제색상(0), 해제굵기(0), 해제상단기준(0), 해제하단기준(0),
      대기활성(0), 대기상단(0), 대기하단(0), 대기경과(0), 대기길이(0),
      확정방향(0), 확정굵기(0), 판정가격(0), 최종해제방향(0);

FX세션키 = WSF_FXSessionKeyV1(sDate,sTime);
FX초기화 = 0;
If CurrentBar == 1 Then FX초기화 = 1;
Else If FX세션키 != FX세션키[1] Then FX초기화 = 1;
If FX초기화 == 1 Then 세션봉수 = 1;
Else 세션봉수 = 세션봉수[1]+1;

WSF_FXSessionProfileV2_CO(FX초기화,가치영역배수,최소봉수,폭계산봉수,
    매물대중심,매물대상단1,매물대하단1,매물대상단2,매물대하단2,
    매물대5상태,매물대유효);

// 최근 N봉 매물대 폭
폭 = 0;
If 매물대유효 == 1 Then 폭 = 매물대상단1-매물대하단1;

// 최근 비율기준봉수(세션 안) 최대 폭 대비 비율
기준창 = Min(Max(1,Round(비율기준봉수,0)),세션봉수);
최대폭 = 0;
For j = 0 To 기준창-1 { 최대폭 = Max(최대폭,폭[j]); };
폭비율 = 0;
If 최대폭 > 0 Then 폭비율 = 폭/최대폭*100;

// 좁음: 최근 N봉 폭이 완전히 채워진 뒤(세션봉수 >= 폭계산봉수)부터 판정
좁음 = 0;
If 매물대유효 == 1 && 최대폭 > 0 && 세션봉수 >= 폭계산봉수 && 폭비율 < 좁음기준 Then 좁음 = 1;

// 연속 지속봉수. 세션 경계에서 새로 시작.
If FX초기화 == 1 Then 압축지속봉수 = 좁음;
Else If 좁음 == 1 Then 압축지속봉수 = 압축지속봉수[1]+1;
Else 압축지속봉수 = 0;

// 압축 해제 신호
압축해제 = 0; 해제방향 = 0; 해제길이 = 0;
If 확정봉판정 == 1 Then
{
    // 직전 완료봉에서 해제됐는지 확인 (그 전 봉까지 압축 지속)
    If CurrentBar > 2 && FX초기화 == 0 && FX초기화[1] == 0 &&
       좁음[1] == 0 && 압축지속봉수[2] >= 단계1봉수 Then
    {
        압축해제 = 1;
        해제길이 = 압축지속봉수[2];
        해제상단기준 = 매물대상단1[2]; 해제하단기준 = 매물대하단1[2];
        If C[1] > 해제상단기준 Then 해제방향 = 1;
        Else If C[1] < 해제하단기준 Then 해제방향 = -1;
    };
}
Else
{
    // 현재 봉에서 해제 (직전 봉까지 압축 지속)
    If CurrentBar > 1 && FX초기화 == 0 && 좁음 == 0 && 압축지속봉수[1] >= 단계1봉수 Then
    {
        압축해제 = 1;
        해제길이 = 압축지속봉수[1];
        해제상단기준 = 매물대상단1[1]; 해제하단기준 = 매물대하단1[1];
        If C > 해제상단기준 Then 해제방향 = 1;
        Else If C < 해제하단기준 Then 해제방향 = -1;
    };
};
해제색상 = RGB(120,120,120);
If 해제방향 == 1 Then 해제색상 = RGB(220,0,0);
If 해제방향 == -1 Then 해제색상 = RGB(0,0,200);
해제굵기 = 3;
If 해제길이 >= 단계3봉수 Then 해제굵기 = 5;
Else If 해제길이 >= 단계2봉수 Then 해제굵기 = 4;

// 방향 확정 대기: 미확정 해제 뒤 방향확정봉수 이내 첫 박스 이탈. 같은 봉 재평가는 직전 봉 상태에서 시작.
If CurrentBar > 1 Then
{
    대기활성 = 대기활성[1]; 대기상단 = 대기상단[1]; 대기하단 = 대기하단[1];
    대기경과 = 대기경과[1]; 대기길이 = 대기길이[1];
};
확정방향 = 0;
If FX초기화 == 1 Then 대기활성 = 0;
판정가격 = C;
If 확정봉판정 == 1 Then 판정가격 = C[1];
If 대기활성 == 1 Then
{
    대기경과 = 대기경과 + 1;
    If 판정가격 > 대기상단 Then 확정방향 = 1;
    Else If 판정가격 < 대기하단 Then 확정방향 = -1;
    If 확정방향 != 0 || 대기경과 >= 방향확정봉수 Then 대기활성 = 0;
};
If 압축해제 == 1 && 해제방향 == 0 && 방향확정봉수 > 0 Then
{
    대기활성 = 1;
    대기상단 = 해제상단기준; 대기하단 = 해제하단기준;
    대기경과 = 0;
    대기길이 = 해제길이;
};
확정굵기 = 3;
If 대기길이 >= 단계3봉수 Then 확정굵기 = 5;
Else If 대기길이 >= 단계2봉수 Then 확정굵기 = 4;
// 다른 지표 연동용: 해제 방향(즉시 확정) 또는 지연 확정 방향
최종해제방향 = 해제방향;
If 확정방향 != 0 Then 최종해제방향 = 확정방향;

지속색상 = RGB(170,170,170);
If 압축지속봉수 >= 단계3봉수 Then 지속색상 = RGB(200,80,0);
Else If 압축지속봉수 >= 단계2봉수 Then 지속색상 = RGB(255,140,0);
Else If 압축지속봉수 >= 단계1봉수 Then 지속색상 = RGB(255,200,120);

If DataCompress == 2 && BarInterval == 1 Then
{
    Plot1(압축지속봉수,"압축지속봉수",지속색상,Def,3);
    If 비율표시 == 1 && 매물대유효 == 1 && 최대폭 > 0 Then Plot2(폭비율,"폭비율",RGB(120,120,120),Def,0);
    Else NoPlot(2);
    If 압축해제 == 1 Then Plot3(해제길이,"압축해제",해제색상,Def,해제굵기);
    Else NoPlot(3);
    If 확정방향 == 1 Then Plot4(대기길이,"방향확정",RGB(220,0,0),Def,확정굵기);
    Else If 확정방향 == -1 Then Plot4(대기길이,"방향확정",RGB(0,0,200),Def,확정굵기);
    Else NoPlot(4);
}
Else
{
    NoPlot(1); NoPlot(2); NoPlot(3); NoPlot(4);
};
