// #우드스탁_해외선물평탄카운트V4  (V3 + 기울기선행 첫이탈 신호)
//   하향첫이탈: 기울기Cnt가 음수로 바뀐 뒤 위치Cnt가 한 번도 0 아래로 안 내려오다가,
//              기울기Cnt <= -(기울기기준+1) 인 상태에서 위치Cnt가 처음 0 아래로 내려온 봉 (Plot8, -신호표시값)
//   상향첫돌파: 대칭 (Plot9, +신호표시값). 한 기울기 구간에 한 번만.
// #우드스탁_해외선물평탄카운트V3  (V2 + Plot7 위치구간진폭을 세션최대 대비 %로 표시)
// #우드스탁_해외선물평탄카운트V2  (하단 지표, 1분봉 기준)  - V1 + 최소구간봉수(3) (WSF_FXFlatCountV2_CO)
//   최소구간봉수 미만으로 끝난 짧은 구간은 Plot3~6 직전 값을 덮어쓰지 않음. 1이면 V1과 같음.
// (아래는 V1 설명)
// #우드스탁_해외선물평탄카운트V1  (하단 지표, 1분봉 기준)  - 곡선회귀선_평탄 카운트 확인용
// 평탄선 = WSF_FXFutureValuesV3_CO의 곡선회귀선_평탄 (미래곡선과 같은 입력)
// 카운트 계산 = WSF_FXFlatCountV2_CO (세션 07:00/15:30 초기화)
// Plot1 위치카운트 : 종가가 평탄선 위(+N, 빨강)/아래(-N, 파랑)에 머문 봉 수. 막대 권장
// Plot2 기울기카운트: 평탄선이 오르는(+N, 진빨강)/내리는(-N, 진파랑) 방향이 이어진 봉 수. 선, 굵기 2
// Plot3 직전상승위치 / Plot4 직전하락위치(음수 표시) : 바로 앞 위치 구간 길이 (기준선 비교용, 연한 색)
// Plot5 직전상승기울기 / Plot6 직전하락기울기(음수 표시) : 바로 앞 기울기 구간 길이 (제목줄 값 확인용)
// Plot7 위치구간진폭(틱) : 현재 위치 구간의 고저 폭 (제목줄 값 확인용, 차트에서 꺼도 됨)
Input : 예측변수(10),
        예측봉수1(5),
        예측봉수2(10),
        예측봉수3(15),
        예측봉수4(30),
        예측봉수5(60),
        최소신뢰도(0.4),
        지속봉수(5),
        마켓계산기간(20),
        최소전환유지봉수(3),
        스윙연결(0),
        기세무시틱(1),
        최소구간봉수(3),
        기울기기준(2),
        신호표시값(3);
Var : 단계화_1분_통합(0), 곡선회귀선_평탄(0), 마켓중심가격(0),
      지속저장목표1(0), 지속저장목표2(0), 지속저장목표3(0), 지속저장목표4(0), 지속저장목표5(0),
      핵심지난상승최고가(0), 핵심지난상승최저가(0), 핵심지난상승_382(0), 핵심지난상승_500(0), 핵심지난상승_618(0),
      핵심지난하락최고가(0), 핵심지난하락최저가(0), 핵심지난하락_382(0), 핵심지난하락_500(0), 핵심지난하락_618(0),
      함수계산가능(0),
      FX세션키(0), FX초기화(0), 카운트유효(0),
      위치Cnt(0), 직전상승위치Cnt(0), 직전하락위치Cnt(0), 위치구간진폭(0),
      기울기Cnt(0), 직전상승기울기Cnt(0), 직전하락기울기Cnt(0),
      위치색(0), 기울기색(0), 세션최대진폭(0), 위치구간진폭율(0),
      하락중위치이탈(0), 상승중위치이탈(0), 하향첫이탈(0), 상향첫돌파(0);

함수계산가능 = WSF_FXFutureValuesV3_CO(
    예측변수,예측봉수1,예측봉수2,예측봉수3,예측봉수4,예측봉수5,
    최소신뢰도,지속봉수,마켓계산기간,최소전환유지봉수,
    단계화_1분_통합,곡선회귀선_평탄,마켓중심가격,
    지속저장목표1,지속저장목표2,지속저장목표3,지속저장목표4,지속저장목표5,
    핵심지난상승최고가,핵심지난상승최저가,핵심지난상승_382,핵심지난상승_500,핵심지난상승_618,
    핵심지난하락최고가,핵심지난하락최저가,핵심지난하락_382,핵심지난하락_500,핵심지난하락_618,
    스윙연결,기세무시틱);

FX세션키 = WSF_FXSessionKeyV1(sDate,sTime);
FX초기화 = 0;
If CurrentBar == 1 Then FX초기화 = 1;
Else If FX세션키 != FX세션키[1] Then FX초기화 = 1;

카운트유효 = WSF_FXFlatCountV2_CO(FX초기화,IFF(함수계산가능 == 1,곡선회귀선_평탄,0),최소구간봉수,
    위치Cnt,직전상승위치Cnt,직전하락위치Cnt,위치구간진폭,
    기울기Cnt,직전상승기울기Cnt,직전하락기울기Cnt);

// 위치구간진폭 % : 세션 초기화 이후 최대 위치구간진폭 대비 (V3)
세션최대진폭 = 세션최대진폭[1];
If FX초기화 == 1 Then 세션최대진폭 = 0;
If 카운트유효 == 1 And 위치구간진폭 > 세션최대진폭 Then 세션최대진폭 = 위치구간진폭;
위치구간진폭율 = IFF(세션최대진폭 > 0,위치구간진폭 / 세션최대진폭 * 100,0);

// 기울기선행 첫이탈 (V4)
하락중위치이탈 = 하락중위치이탈[1];
상승중위치이탈 = 상승중위치이탈[1];
하향첫이탈 = 0;
상향첫돌파 = 0;
If FX초기화 == 1 Then
{
    하락중위치이탈 = 1; 상승중위치이탈 = 1;
};
If 카운트유효 == 1 And FX초기화 == 0 Then
{
    // 새 하락/상승 기울기 구간 시작 시 기록 초기화
    If 기울기Cnt < 0 And 기울기Cnt[1] >= 0 Then 하락중위치이탈 = 0;
    If 기울기Cnt > 0 And 기울기Cnt[1] <= 0 Then 상승중위치이탈 = 0;

    If 기울기Cnt < -기울기기준 And 하락중위치이탈 == 0 And 위치Cnt < 0 And 위치Cnt[1] >= 0 Then 하향첫이탈 = 1;
    If 기울기Cnt > 기울기기준 And 상승중위치이탈 == 0 And 위치Cnt > 0 And 위치Cnt[1] <= 0 Then 상향첫돌파 = 1;

    // 기울기 구간 중 위치가 한 번이라도 반대로 가면 그 구간은 끝 (신호 후에도 재발생 없음)
    If 기울기Cnt < 0 And 위치Cnt < 0 Then 하락중위치이탈 = 1;
    If 기울기Cnt > 0 And 위치Cnt > 0 Then 상승중위치이탈 = 1;
};

If 카운트유효 == 1 Then
{
    위치색 = IFF(위치Cnt > 0,RGB(255,150,150),IFF(위치Cnt < 0,RGB(150,170,255),RGB(180,180,180)));
    기울기색 = IFF(기울기Cnt > 0,RGB(200,0,0),IFF(기울기Cnt < 0,RGB(0,0,200),RGB(120,120,120)));
    Plot1(위치Cnt,"위치카운트",위치색,Def,3);
    Plot2(기울기Cnt,"기울기카운트",기울기색,Def,2);
    Plot3(직전상승위치Cnt,"직전상승위치",RGB(255,200,200),Def,0);
    Plot4(-직전하락위치Cnt,"직전하락위치",RGB(200,210,255),Def,0);
    Plot5(직전상승기울기Cnt,"직전상승기울기",RGB(230,120,120),Def,0);
    Plot6(-직전하락기울기Cnt,"직전하락기울기",RGB(120,140,230),Def,0);
    Plot7(위치구간진폭율,"위치구간진폭%",RGB(150,150,150),Def,0);
    If 하향첫이탈 == 1 Then Plot8(-신호표시값,"하향첫이탈",RGB(0,0,255),Def,10); Else NoPlot(8);
    If 상향첫돌파 == 1 Then Plot9(신호표시값,"상향첫돌파",RGB(255,0,0),Def,10); Else NoPlot(9);
}
Else
{
    NoPlot(1); NoPlot(2); NoPlot(3); NoPlot(4); NoPlot(5); NoPlot(6); NoPlot(7); NoPlot(8); NoPlot(9);
};
