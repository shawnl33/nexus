// #WSF_해외선물지속목표차삼선V1: 5/10/15분 지속목표 간격 하단 지표.
// 한국시간 1분봉. 07:00/15:30 구간 초기화. 전일 변수는 직전 구간을 뜻한다.
Input : 예측변수(10),
        예측봉수1(5),
        예측봉수2(10),
        예측봉수3(15),
        예측봉수4(30),
        예측봉수5(60),
        최소신뢰도(0.4),
        지속봉수(5),
        마켓계산기간(20),
        최소전환유지봉수(3),
        비율강조기준(25);
Var : 단계화_1분_통합(0),
      곡선회귀선_평탄(0),
      마켓중심가격(0),
      지속저장목표1(0),
      지속저장목표2(0),
      지속저장목표3(0),
      지속저장목표4(0),
      지속저장목표5(0),
      핵심지난상승최고가(0),
      핵심지난상승최저가(0),
      핵심지난상승_382(0),
      핵심지난상승_500(0),
      핵심지난상승_618(0),
      핵심지난하락최고가(0),
      핵심지난하락최저가(0),
      핵심지난하락_382(0),
      핵심지난하락_500(0),
      핵심지난하락_618(0),
      함수계산가능(0);

함수계산가능 = WSF_FXFutureValuesV1(
    예측변수,
    예측봉수1,
    예측봉수2,
    예측봉수3,
    예측봉수4,
    예측봉수5,
    최소신뢰도,
    지속봉수,
    마켓계산기간,
    최소전환유지봉수,
    단계화_1분_통합,
    곡선회귀선_평탄,
    마켓중심가격,
    지속저장목표1,
    지속저장목표2,
    지속저장목표3,
    지속저장목표4,
    지속저장목표5,
    핵심지난상승최고가,
    핵심지난상승최저가,
    핵심지난상승_382,
    핵심지난상승_500,
    핵심지난상승_618,
    핵심지난하락최고가,
    핵심지난하락최저가,
    핵심지난하락_382,
    핵심지난하락_500,
    핵심지난하락_618
);
Var : 지속목표차(0), 지속목표차_최고(0), 지속목표차_전일최고(0),
      지속목표차_비율(0), 지속목표차_전일비율(0),
      지속목표_최고(0), 지속목표_최저(0), 지속목표_Cnt(0),
      세션키(0), 세션초기화(0), 구간최저가(0), 목표준비(0);
// 계산 시작: 최초 유효 폭도 0을 포함하여 기록한다.
세션키 = WSF_FXSessionKeyV1(sDate,sTime);
세션초기화 = 0;
If CurrentBar == 1 Then 세션초기화 = 1;
Else If 세션키 != 세션키[1] Then 세션초기화 = 1;

If 세션초기화 == 1 Then
{
    지속목표차 = 0;
    지속목표차_최고 = 0;
    지속목표차_전일최고 = 0;
    If CurrentBar > 1 Then 지속목표차_전일최고 = 지속목표차_최고[1];
    지속목표차_비율 = 0;
    지속목표차_전일비율 = 0;
    지속목표_Cnt = 0;
    구간최저가 = L;
}
Else
{
    지속목표차_최고 = 지속목표차_최고[1];
    지속목표차_전일최고 = 지속목표차_전일최고[1];
    구간최저가 = Min(구간최저가[1],L);
};

목표준비 = 0;
If 함수계산가능 == 1 && 지속저장목표1 != 0 && 지속저장목표2 != 0 && 지속저장목표3 != 0 Then 목표준비 = 1;
지속목표_최고 = 0; 지속목표_최저 = 0;
지속목표차 = 0; 지속목표차_비율 = 0; 지속목표차_전일비율 = 0;
If 목표준비 == 1 Then
{
    지속목표_최고 = Max(Max(지속저장목표1,지속저장목표2),지속저장목표3);
    지속목표_최저 = Min(Min(지속저장목표1,지속저장목표2),지속저장목표3);
    // 매 봉 평가하므로 어느 목표가 바뀌어도 폭과 색상이 즉시 반영된다.
    지속목표차 = 지속목표_최고-지속목표_최저;
    지속목표차_최고 = Max(지속목표차_최고,지속목표차);
    If 지속목표차_최고 > 0 Then
        지속목표차_비율 = 지속목표차/지속목표차_최고*100;
    If 지속목표차_전일최고 > 0 Then
        지속목표차_전일비율 = 지속목표차/지속목표차_전일최고*100;

    If 세션초기화 == 1 || 목표준비[1] == 0 || 지속목표차 != 지속목표차[1] Then
        지속목표_Cnt = 1;
    Else 지속목표_Cnt = 지속목표_Cnt[1]+1;
}
Else 지속목표_Cnt = 0;
// 계산 끝
If 목표준비 == 1 Then
{
    Plot1(지속목표차,"지속목표차");
    Plot2(지속목표차_최고,"구간최고폭");
    If 지속목표차_전일최고 > 0 Then Plot3(지속목표차_전일최고,"직전구간최고폭");
    Else NoPlot(3);
    Plot4(지속목표차_비율,"구간최고대비비율",
        IFF(구간최저가 > 지속목표_최저,RGB(255,0,255),
        IFF(지속목표차_비율 < 비율강조기준 && H < 지속목표_최저,RGB(0,0,255),
        IFF(지속목표차_비율 < 비율강조기준 && L > 지속목표_최고,RGB(255,0,0),RGB(128,128,128)))),
        Def,IFF(지속목표차_비율 < 비율강조기준,2,1));
    If 지속목표차_전일최고 > 0 Then
        Plot5(지속목표차_전일비율,"직전구간최고대비비율",
            IFF(구간최저가 > 지속저장목표3 && L > 지속목표_최고,RGB(255,0,0),RGB(128,128,128)));
    Else NoPlot(5);
    Plot6(지속목표_Cnt,"동일폭유지봉수");
}
Else
{
    NoPlot(1); NoPlot(2); NoPlot(3); NoPlot(4); NoPlot(5); NoPlot(6);
};
