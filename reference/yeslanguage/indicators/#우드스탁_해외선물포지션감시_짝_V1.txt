// #우드스탁_해외선물포지션감시_짝_V1  (지표, 같은 차트의 시스템 포지션을 I_ 함수로 감시)
//   원본 포지션 감시 지표 + 버그 수정. 계산 방식·Plot 구성은 원본과 같고 아래 [수정] 부분만 바뀜.
//   [수정1] 반대 방향 바로 전환(매수->매도 등)도 청산으로 정산. 원본은 0으로 청산될 때만 정산 -> 전환 거래 손익 누락.
//   [수정2] 최종 청산가 = 청산 봉 종가 (원본은 직전 봉 종가). OnClose 청산은 정확, 지정가/역지정가 청산은 근사값.
//           일부청산가 = 평균진입가 ± 일부청산틱(10) (짝_V3 1차 지정가와 같음). 일부청산틱 = 0 이면 종가.
//   [수정3] 일부청산 손익에 청산 수량을 곱함. 보유수량이 늘어난 것(추가 진입)은 청산으로 세지 않음.
//   [수정4] 최종 청산 수량 = 직전 봉 보유수량 (원본 최초진입수량 2 / 일부청산수량 1 고정값 대신). I_CurrentContracts 는 매도 음수라 Abs 사용.
//   [수정5] 최종청산손익의 DayIndex > 0 조건 삭제 (0시 첫 봉 청산 누락).
//   [수정6] 수익회수/손실회수 = 이번 거래 손익 기준 (원본은 당일 누적손익이 플러스인지로 셈).
//   [수정7] 틱배율(1): 모든 틱 기준값(100~600틱, -21틱 등)의 단위 = PriceScale x 틱배율. 1 이면 원본과 같음.
//           Plot 값도 이 단위로 표시됨 (예: 틱배율 0.2 면 기준·표시가 5배 -> 국내 0.05 기준값을 0.25 틱 종목에 맞출 때 조정).
//   [수정8] 파일 끝 닫히지 않은 /* 주석 닫음.
//   변경 없음: 매도수익보전비율 기본값 0 (매수 0.3), 안 쓰는 Input 매수손절·목표수익률·Var 손절가.

	  //////////////////////////////////////

   거래손익 = 청산손익 + (C - I_AvgEntryPrice[1])*I_MarketPosition[1]*직전수량;

   If I_MarketPosition[1] > 0 Then 최종청산손익_매수 = 최종청산손익_매수 + 거래손익;

		진입손실_매수 = Min(L - I_AvgEntryPrice, 진입손실_매수[1]); 
		진입손익_매수 = C - I_AvgEntryPrice;
	   }

       If I_MarketPosition < 0 Then //매도포지션
       {
	    진입수익_매도 = Max(I_AvgEntryPrice-L, 진입수익_매도[1]);
		진입손실_매도 = Min(I_AvgEntryPrice-H, 진입손실_매도[1]); 
		진입손익_매도 = I_AvgEntryPrice - C;
	   }

          }

   }
