//======================================================================
// OSF_VolFlowV1
// 거래량 가중 방향(Chaikin Money Flow 방식) 매수/매도 흐름 함수
// 종가위치(CLV, -1~+1 스케일)에 거래량을 곱해 기간 누적한 뒤
// 같은 기간 총거래량으로 나눠 "거래량 강도"까지 반영한 방향성을 추정한다.
// 해외선물도 Volume(총거래량)은 제공되므로 사용 가능.
//
// 계산식:
//   MFM(봉당) = ((종가-저가) - (고가-종가)) / (고가-저가)       (-1 ~ +1)
//   MFV(봉당) = MFM * Volume
//   흐름값   = Average(MFV, n) / Average(Volume, n) * 100      (-100 ~ +100)
//   (Average(x,n)*n / Average(y,n)*n 와 동일하므로 굳이 합계를 따로 구하지 않고
//    Average 비율로 계산 - n봉 누적 매수/매도 거래량 우세를 나타낸다)
// OSF_ClvPressureV1과 동일 인터페이스(점수/기울기/상태/유효)로 출력한다.
//======================================================================
Input : 관심기준입력(Numeric),
        강세기준입력(Numeric),
        부호반전입력(Numeric),
        계산기간입력(Numeric),
        흐름점수(NumericRef),
        흐름기울기3(NumericRef),
        흐름상태(NumericRef),
        흐름유효(NumericRef);

Var : 봉범위(0),
      원시MFM(0),
      원시MFV(0),
      기간(0),
      평균MFV(0),
      평균거래량(0),
      계산흐름(0),
      계산기울기3(0),
      계산상태(0),
      관심기준값(0),
      강세기준값(0);

관심기준값 = Abs(관심기준입력);
If 관심기준값 < 1 Then
    관심기준값 = 1;

강세기준값 = Abs(강세기준입력);
If 강세기준값 < 관심기준값 Then
    강세기준값 = 관심기준값;

기간 = Round(계산기간입력, 0);
If 기간 < 2 Then
    기간 = 2;

봉범위 = H - L;

If 봉범위 > 0 Then
    원시MFM = ((C - L) - (H - C)) / 봉범위;
Else
    원시MFM = 0;

원시MFV = 원시MFM * Volume;

평균MFV = Average(원시MFV, 기간);
평균거래량 = Average(Volume, 기간);

If 평균거래량 > 0 Then
    계산흐름 = 평균MFV / 평균거래량 * 100;
Else
    계산흐름 = 0;

If 부호반전입력 == 1 Then
    계산흐름 = -계산흐름;

If CurrentBar >= 기간 + 3 Then
    계산기울기3 = 계산흐름 - 계산흐름[3];
Else
    계산기울기3 = 0;

If 계산기울기3 > 100 Then
    계산기울기3 = 100;
If 계산기울기3 < -100 Then
    계산기울기3 = -100;

계산상태 =
    IFF(계산흐름 >= 강세기준값, 2,
    IFF(계산흐름 >= 관심기준값, 1,
    IFF(계산흐름 <= -강세기준값, -2,
    IFF(계산흐름 <= -관심기준값, -1, 0))));

흐름점수 = 계산흐름;
흐름기울기3 = 계산기울기3;
흐름상태 = 계산상태;
흐름유효 = IFF(CurrentBar >= 기간, 1, 0);

Value1 = 1;
OSF_VolFlowV1 = Value1;
