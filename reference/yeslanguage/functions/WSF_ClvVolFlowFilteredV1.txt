//======================================================================
// WSF_ClvVolFlowFilteredV1
// 거래량흐름결합(WSF_ClvVolFlowV1) 신호를 상대거래량(WSF_RelVolV1)으로
// 가중/감쇠하는 유동성 필터 결합 함수.
//
// 결합 규칙 (WSF_ClvVolFlowV1의 CLV/거래량흐름 결합 방식과 동일한 사고):
//   - 방향(부호)은 항상 WSF_ClvVolFlowV1의 결합점수 부호를 그대로 따른다
//     -> RVOL은 신뢰도(크기)만 조절하고 방향을 뒤집지 않는다
//   - RVOL상태 == 2 (평균 대비 강세, 유동성 충분) : 결합점수를 1.2배로 강화
//   - RVOL상태 == 1 (평균 대비 관심 수준)         : 결합점수를 그대로 사용
//   - RVOL상태 == 0 (평균 이하, 저유동성 의심)     : 결합점수를 0.5배로 약화
//   - WSF_ClvVolFlowV1 결합점수가 정확히 0이면 필터링해도 0(중립)
// 유효 여부는 두 하위 함수가 모두 유효할 때만 1 (워밍업 기간이 더 긴 쪽을 따름)
//======================================================================
Input : 관심기준입력(Numeric),
        강세기준입력(Numeric),
        부호반전입력(Numeric),
        계산기간입력(Numeric),
        RVOL계산기간입력(Numeric),
        RVOL관심기준입력(Numeric),
        RVOL강세기준입력(Numeric),
        필터결합점수(NumericRef),
        필터결합기울기3(NumericRef),
        필터결합상태(NumericRef),
        필터결합유효(NumericRef);

Var : 결합점수(0), 결합기울기(0), 결합상태(0), 결합유효(0),
      RVOL점수(0), RVOL기울기(0), RVOL상태(0), RVOL유효(0),
      계산필터(0),
      계산기울기3(0),
      계산상태(0),
      관심기준값(0),
      강세기준값(0);

관심기준값 = Abs(관심기준입력);
If 관심기준값 < 1 Then
    관심기준값 = 1;

강세기준값 = Abs(강세기준입력);
If 강세기준값 < 관심기준값 Then
    강세기준값 = 관심기준값;

// 하위 함수는 방향반전 없이(0) 원점수로 호출하고, 반전은 마지막 단계에서 한 번만 적용
WSF_ClvVolFlowV1(
    관심기준입력, 강세기준입력, 0, 계산기간입력,
    결합점수, 결합기울기, 결합상태, 결합유효
);

WSF_RelVolV1(
    RVOL관심기준입력, RVOL강세기준입력, RVOL계산기간입력,
    RVOL점수, RVOL기울기, RVOL상태, RVOL유효
);

If 결합점수 == 0 Then
    계산필터 = 0;
Else If RVOL상태 == 2 Then
    계산필터 = 결합점수 * 1.2;
Else If RVOL상태 == 1 Then
    계산필터 = 결합점수;
Else
    계산필터 = 결합점수 * 0.5;

If 부호반전입력 == 1 Then
    계산필터 = -계산필터;

If 계산필터 > 100 Then
    계산필터 = 100;
If 계산필터 < -100 Then
    계산필터 = -100;

If CurrentBar >= Round(계산기간입력,0) + 3 Then
    계산기울기3 = 계산필터 - 계산필터[3];
Else
    계산기울기3 = 0;

If 계산기울기3 > 100 Then
    계산기울기3 = 100;
If 계산기울기3 < -100 Then
    계산기울기3 = -100;

계산상태 =
    IFF(계산필터 >= 강세기준값, 2,
    IFF(계산필터 >= 관심기준값, 1,
    IFF(계산필터 <= -강세기준값, -2,
    IFF(계산필터 <= -관심기준값, -1, 0))));

필터결합점수 = 계산필터;
필터결합기울기3 = 계산기울기3;
필터결합상태 = 계산상태;
필터결합유효 = IFF(결합유효 == 1 && RVOL유효 == 1, 1, 0);

Value1 = 1;
WSF_ClvVolFlowFilteredV1 = Value1;
