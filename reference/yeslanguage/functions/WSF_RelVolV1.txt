//======================================================================
// WSF_RelVolV1
// 상대거래량(Relative Volume) 필터 함수
// 현재 봉 거래량이 최근 n봉 평균 거래량 대비 몇 %인지 측정한다.
// WSF_ClvPressureV1 / WSF_VolFlowV1 / WSF_ClvVolFlowV1 등 방향성 지표가
// 저유동성 구간에서 발생한 노이즈성 신호인지 걸러내는 유동성 필터 용도.
// (방향성이 없는 순수 크기 지표이므로 부호반전 입력은 없음)
//
// 계산식:
//   RVOL(%) = Volume / Average(Volume, n) * 100
//   (100 = 평균 수준, 150 = 평균의 1.5배, 50 = 평균의 절반)
// 기존 함수들과 동일하게 점수/기울기/상태/유효 인터페이스로 출력한다.
// (상태는 비방향성이라 0/1/2 세 단계만 사용: 0=평균 이하, 1=관심, 2=강세)
//======================================================================
Input : 관심기준입력(Numeric),
        강세기준입력(Numeric),
        계산기간입력(Numeric),
        RVOL점수(NumericRef),
        RVOL기울기3(NumericRef),
        RVOL상태(NumericRef),
        RVOL유효(NumericRef);

Var : 기간(0),
      평균거래량(0),
      계산RVOL(0),
      계산기울기3(0),
      계산상태(0),
      관심기준값(0),
      강세기준값(0);

관심기준값 = Abs(관심기준입력);
If 관심기준값 < 1 Then
    관심기준값 = 1;

강세기준값 = Abs(강세기준입력);
If 강세기준값 < 관심기준값 Then
    강세기준값 = 관심기준값;

기간 = Round(계산기간입력, 0);
If 기간 < 2 Then
    기간 = 2;

평균거래량 = Average(Volume, 기간);

If 평균거래량 > 0 Then
    계산RVOL = Volume / 평균거래량 * 100;
Else
    계산RVOL = 100;

If CurrentBar >= 기간 + 3 Then
    계산기울기3 = 계산RVOL - 계산RVOL[3];
Else
    계산기울기3 = 0;

계산상태 =
    IFF(계산RVOL >= 강세기준값, 2,
    IFF(계산RVOL >= 관심기준값, 1, 0));

RVOL점수 = 계산RVOL;
RVOL기울기3 = 계산기울기3;
RVOL상태 = 계산상태;
RVOL유효 = IFF(CurrentBar >= 기간, 1, 0);

Value1 = 1;
WSF_RelVolV1 = Value1;
