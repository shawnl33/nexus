// 표시실험5. 회귀선처럼 봉마다 값이 바뀌고, 색이 10봉마다 바뀐다.
// 맨 앞 40봉만 보이게 하고, 범례가 나오게 전체 창을 캡처한다.
// 볼 것: 매 봉이 계단인지 사선인지, 색이 바뀌는 이음이 어느 색인지.

Var : n(0), lv(0);
n = CurrentBar;
lv = 100 + n;

If n <= 10 Then
{
    Plot1(lv,"매봉색",RGB(255,0,0),Def,3);
}
Else If n <= 20 Then
{
    Plot1(lv,"매봉색",RGB(0,0,255),Def,3);
}
Else If n <= 30 Then
{
    Plot1(lv,"매봉색",RGB(255,0,0),Def,3);
};
