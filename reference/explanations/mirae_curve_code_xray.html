왜 점수의 ‘미래’와 그림의 ‘미래’가 다른가요?
점수의 미래 재료(±2)는 WSF_Htf_CurvePredict — 회귀 직선을 10봉 앞으로 그대로 연장한 값(원시 미래)의 부호입니다. 화면의 부채꼴은 WSF_Mtf_LinRegPredictV4 — 같은 직선을 R²·ATR 상한으로 눌러주고 둔화까지 반영한 값입니다. 그래서 점수는 ±2로 크게 흔들리면서도 그림은 짧고 조심스럽게 그려질 수 있습니다. 심판은 낙관적으로(날것), 그림은 보수적으로(눌림) — 이중 안전장치입니다. 위 ⑤번 상자에서 R²나 기울기를 바꾸면 이 차이를 직접 확인할 수 있습니다.

3읽는 법과 한계

  1. 왼쪽 차트에서 T를 옮기거나, 위 조종판에서 변수를 바꿔 보세요. 값이 오렌지색이면 실제 데이터가 아니라 ‘가정(what-if)’ 값입니다.
  2. 오른쪽 흐름도는 위에서 아래로 — 입력 변수 → 문지기(GATE) → V4 5단계 → 오차띠 → 점수 합산 → 출력 순서입니다. 초록 테두리는 통과, 빨간 테두리는 막힘입니다.
  3. 차트의 부채꼴(목표선 3개 + 점선 띠)과 하단 점수 막대는 흐름도의 출력과 같은 값입니다. 흐름도의 숫자가 차트의 어떤 선으로 나타나는지 번호를 따라가 보세요.
한계. 이 데이터에는 호가 잔량이 없어 호가 심판은 가상 조종입니다. 매매 상태(Plot30/31)·일봉 마켓 밴드(Plot52~55)·지난예측(Plot20~22)은 일봉/호가 헬퍼가 필요해 생략했습니다. 실제 HTS는 목표선을 현재 봉의 짧은 선분(트렌드라인)으로 그리며, 여기서는 이해를 위해 미래 방향으로 연장해 그립니다. 방향 기억선은 근사(10봉 예측방향 2봉 확인)이며, 실제 코드는 일봉/갭 기본방향 우선 + 호가 관성 지연(전환 유예)이 있습니다. 모든 값은 같은 수식으로 다시 계산한 근사치입니다.
